那第 16 张是什么

口径张数说明
APP 卡包16含今天（10-10 周六）05:00-10:29 那张早餐券，虽已过期但仍在列表
MCP「可用券」15服务端把已过期/已失效的券剔掉，未来日期的券仍保留
早餐券按「周一~周日轮转、每天一张」发放（10-17/10-18 同为巧克力味厚松饼，可见周六周日同款）， 而 10-10 当天 16:02 已越过 10:29，故 MCP 不再返回——差额 1 张由此而来。

顺带修掉一个真 Bug：双渠道标签被误判

证据

第 1 张「9.9元中杯冰美式」的标签是 到店专用、外送专用——两个渠道都能用。 旧代码按关键词顺序先命中「外送」，把它判成了外送专用，于是到店场景会本地把它剔除。 而深圳蛇口案例里，正是这张券贡献了 ¥9.10 优惠。

修复

修复前
if any(k in t for k in DELIVERY):
    return "delivery"     # ← 误判
if any(k in t for k in DINE_IN):
    return "dine_in"
return None
修复后
has_delivery = any(k in t for k in DELIVERY)
has_dine_in  = any(k in t for k in DINE_IN)
if has_delivery and has_dine_in:
    return None           # ← 双渠道 = 不限渠道
if has_delivery: return "delivery"
if has_dine_in:  return "dine_in"
return None

验证

真机复跑：该券 channel = None（不限渠道）； 新增 7 条 TDD 契约，离线测试 170 passed（原 163）。 另新增 audit_my_coupons()，一条命令输出「声明数 / 解析数 / 当时可用数 / 过期·未生效·时段外」拆分。
